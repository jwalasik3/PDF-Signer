Detailed Description

Utility class for monitoring the presence of removable (USB) drives.

The DriveCheck class provides functionality to periodically scan the system's root directories to detect if a USB drive is connected. It keeps track of the detection status and the path to the detected USB drive.

void com.example.pdfsignergui.DriveCheck.checkForDrive ( ) throws Exception
private

Scans the system's root directories to detect the presence of a removable drive.

This method iterates through all available file system roots, checks their type (e.g., FAT, exFAT) and properties (readability, total space) to identify potential removable drives. It updates the isDetected flag and usbDrive field based on the scan results.

Exceptions
ExceptionIf an unexpected error occurs during file system access. (Note: Expected inaccessible drive exceptions are caught internally).

◆ startDriveMonitoring()

void com.example.pdfsignergui.DriveCheck.startDriveMonitoring ( )

Starts a background thread to continuously monitor for USB drives.

This method initializes a java.util.Timer and schedules a java.util.TimerTask to execute the checkForDrive() method periodically (every 2 seconds). The monitoring runs on a daemon thread, allowing the application to exit cleanly.

The action to be performed by this timer task.

This method is executed repeatedly by the timer and calls checkForDrive() to check for USB drive presence. Exceptions during this check are ignored to ensure continuous monitoring.
