Detailed Description

Utility class for signing and verifying PDF files.

The PdfSignerUtil class provides static methods to handle the digital signing of PDF documents, decryption of private keys from encrypted files, and the verification of existing digital signatures within PDFs. It leverages the iText library for PDF manipulation and signing, and BouncyCastle for cryptographic operations.

Decrypts a private key from an encrypted file using a provided PIN.

This method reads the encrypted private key, salt, and Initialization Vector (IV) from the specified file. It then derives an AES key from the PIN using PBKDF2 and decrypts the private key data. Finally, it converts the decrypted bytes into an RSA PrivateKey object.

Parameters
encryptedFileThe java.io.File containing the encrypted private key, salt, and IV.
pinThe PIN string used to derive the decryption key.
Returns
The decrypted java.security.PrivateKey object.
Exceptions
ExceptionIf there are issues reading the file, deriving the key, decrypting the data, or converting the key bytes to a PrivateKey object.

Loads a certificate chain from the pre-defined certificate path (CERT_PATH).

This method attempts to read an X.509 certificate from the file specified by CERT_PATH. This certificate is essential for both signing the PDF (as it contains the public key corresponding to the private key) and for verifying the signature.

Returns
An array of java.security.cert.Certificate objects, containing the loaded X.509 certificate.
Exceptions
FileNotFoundExceptionIf the certificate file specified by CERT_PATH does not exist.
ExceptionIf any other error occurs during the certificate loading process (e.g., invalid certificate format).

Digitally signs a PDF document using a private key and a certificate chain.

This method takes a source PDF file, decrypts a private key from an encrypted file on a USB drive using a provided PIN, and then applies a digital signature to the PDF. The signed PDF is saved to a specified destination path.

Parameters
srcPdfPathThe java.io.File object representing the source, unsigned PDF.
destPdfPathThe java.io.File object where the signed PDF will be saved.
usbPathThe java.io.File object pointing to the encrypted private key file on the USB.
pinThe PIN (Personal Identification Number) required to decrypt the private key.
Exceptions
ExceptionIf any error occurs during PDF reading/writing, key decryption, certificate loading, or the signing process itself.

◆ verifySignature()

boolean com.example.pdfsignergui.PdfSignerUtil.verifySignature ( File pdfPath)
static

Verifies the digital signatures present in a PDF document.

This method opens the specified PDF, iterates through all its form fields to find signature fields, and then verifies the integrity and authenticity of each signature using iText's PdfPKCS7 utility. It also compares the public key embedded in the signature with a locally loaded public key to ensure the signature was made by the expected entity.

Parameters
pdfPathThe java.io.File object representing the PDF document to be verified.
Returns
true if all found signatures are valid and match the locally provided public key; false otherwise, or if no signatures are found, or if an error occurs during the verification process.
