Detailed Description

Controller class for the main-view.fxml.

This class handles user interactions within the key generation application. It manages the input fields for PIN, USB path, and public key path, and triggers the RSA key generation and private key encryption process using the RSAKeyGenAndEncrypt utility. It also updates the UI with feedback on the operation's success or failure.

◆ generateKeys()

void com.example.pdfsignerkeygen.MainController.generateKeys ( ) throws Exception
protected

Handles the action triggered when the "Generate Keys" button is clicked.

This method retrieves the PIN from pinField and the USB path from usbPathField. It then calls the static encode method of RSAKeyGenAndEncrypt to perform the key generation and encryption. It updates the responseLabel with the outcome of the operation.

Exceptions
ExceptionIf an unhandled error occurs during the key generation or encryption process. (Note: Exceptions from RSAKeyGenAndEncrypt.encode are caught and displayed).
