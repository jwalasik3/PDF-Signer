\doxysubsection{Detailed Description}
Utility class for monitoring the presence of removable (USB) drives. 

The {\ttfamily \doxylink{classcom_1_1example_1_1pdfsignergui_1_1_drive_check}{Drive\+Check}} class provides functionality to periodically scan the system\textquotesingle{}s root directories to detect if a USB drive is connected. It keeps track of the detection status and the path to the detected USB drive.

Scans the system\textquotesingle{}s root directories to detect the presence of a removable drive. 

This method iterates through all available file system roots, checks their type (e.\+g., FAT, ex\+FAT) and properties (readability, total space) to identify potential removable drives. It updates the {\ttfamily is\+Detected} flag and {\ttfamily usb\+Drive} field based on the scan results.

Starts a background thread to continuously monitor for USB drives. 

This method initializes a {\ttfamily \doxylink{}{java.\+util.\+Timer}} and schedules a {\ttfamily \doxylink{}{java.\+util.\+Timer\+Task}} to execute the {\ttfamily \doxylink{classcom_1_1example_1_1pdfsignergui_1_1_drive_check_a5fbfb0705b991355562735861a941a14}{check\+For\+Drive()}} method periodically (every 2 seconds). The monitoring runs on a daemon thread, allowing the application to exit cleanly. The action to be performed by this timer task.

This method is executed repeatedly by the timer and calls {\ttfamily \doxylink{classcom_1_1example_1_1pdfsignergui_1_1_drive_check_a5fbfb0705b991355562735861a941a14}{check\+For\+Drive()}} to check for USB drive presence. Exceptions during this check are ignored to ensure continuous monitoring.
