\doxysubsection{Detailed Description}
Utility class for signing and verifying PDF files. 

The {\ttfamily \doxylink{classcom_1_1example_1_1pdfsignergui_1_1_pdf_signer_util}{Pdf\+Signer\+Util}} class provides static methods to handle the digital signing of PDF documents, decryption of private keys from encrypted files, and the verification of existing digital signatures within PDFs. It leverages the i\+Text library for PDF manipulation and signing, and Bouncy\+Castle for cryptographic operations.

Decrypts a private key from an encrypted file using a provided PIN. 

This method reads the encrypted private key, salt, and Initialization Vector (IV) from the specified file. It then derives an AES key from the PIN using PBKDF2 and decrypts the private key data. Finally, it converts the decrypted bytes into an RSA {\ttfamily Private\+Key} object.

Verifies the digital signatures present in a PDF document. 

This method opens the specified PDF, iterates through all its form fields to find signature fields, and then verifies the integrity and authenticity of each signature using i\+Text\textquotesingle{}s {\ttfamily Pdf\+PKCS7} utility. It also compares the public key embedded in the signature with a locally loaded public key to ensure the signature was made by the expected entity.
