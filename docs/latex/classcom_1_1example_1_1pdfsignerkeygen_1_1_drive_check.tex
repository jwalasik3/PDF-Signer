\doxysubsection{Detailed Description}
Utility class for monitoring the presence of removable (USB) drives. 

The {\ttfamily \doxylink{classcom_1_1example_1_1pdfsignerkeygen_1_1_drive_check}{Drive\+Check}} class continuously scans the system\textquotesingle{}s root directories to detect if a USB drive is connected. When a drive is detected or removed, it updates the associated {\ttfamily \doxylink{classcom_1_1example_1_1pdfsignerkeygen_1_1_main_controller}{Main\+Controller}} with the USB drive\textquotesingle{}s path, allowing the UI to reflect the current status.
