\doxysubsection{Detailed Description}
Controller class for the main-\/view.\+fxml. 

This class handles user interactions within the key generation application. It manages the input fields for PIN, USB path, and public key path, and triggers the RSA key generation and private key encryption process using the {\ttfamily \doxylink{classcom_1_1example_1_1pdfsignerkeygen_1_1_r_s_a_key_gen_and_encrypt}{RSAKey\+Gen\+And\+Encrypt}} utility. It also updates the UI with feedback on the operation\textquotesingle{}s success or failure.
