\doxysubsection{Detailed Description}
Utility class for generating RSA key pairs and encrypting private keys. 

This class provides functionality to generate an RSA 4096-\/bit key pair, encrypt the private key using AES encryption with a PIN-\/derived key (PBKDF2), and save the encrypted private key and the public key (along with a self-\/signed X.\+509 certificate) to specified file paths.

Generates an RSA key pair, encrypts the private key, and saves keys and a self-\/signed certificate to files. 

This is the main entry point for the key generation and encryption process. It performs the following steps\+:
\begin{DoxyEnumerate}
\item Generates a 4096-\/bit RSA key pair.
\item Generates a self-\/signed X.\+509 certificate using the generated key pair.
\item Derives an AES encryption key from the provided PIN using PBKDF2 with a random salt.
\item Encrypts the RSA private key using the derived AES key and a random IV.
\item Saves the encrypted private key (along with the salt) to the specified USB path.
\item Saves the RSA public key (Base64 encoded) to the specified public key path.
\item Creates necessary parent directories if they don\textquotesingle{}t exist and attempts to set the private key file as hidden.
\end{DoxyEnumerate}
